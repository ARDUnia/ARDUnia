## About

ARDUnia is a personal technology initiative focused on practical electronics, embedded systems, IoT, automation, open-source development, and AI-powered solutions.

Projects include work with ESP32, ESP8266, Arduino, internet radio, audio systems, Persian software libraries, and AI-enabled IoT applications.
